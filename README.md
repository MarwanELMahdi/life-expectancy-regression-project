# Life Expectancy Regression Project

A regression project that predicts life expectancy using health, social, and economic factors.

## Project Workflow

1. Data Understanding
2. Exploratory Data Analysis (EDA)
3. Data Cleaning
4. Feature Engineering
5. Feature Encoding
6. Feature Scaling
7. Regression Modeling
8. Model Evaluation
9. Residual Analysis
10. Visualization & Comparison

## Dataset
WHO Life Expectancy Dataset from Kaggle.

## Models Implemented
- Numerical Linear Regression
- Statistical Linear Regression
- Multiple Linear Regression using Gradient Descent
- Ridge Regression
- Lasso Regression

## Techniques Used
- Data Cleaning
- Missing Values Handling
- Correlation Analysis
- Feature Selection
- One Hot Encoding
- Target Mean Encoding
- Z-Score Standardization
- Residual Analysis
- Interactive Visualization

- pandas
